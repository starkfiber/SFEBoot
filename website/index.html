Connect the local app Setup once · files stay on your computer

A short setup, once.

  1. Install SFEBoot from the source download using Node.js 22 or newer.
  2. Use the commands below to generate an access token and start the local app.
  3. Copy the token shown in your terminal into the field here. Then connect.
Install & start on macOS / Linux

Download and unzip the source. Open Terminal in the folder containing sfeboot, then run:

npm install -g ./sfeboot
export SFEBOOT_TOKEN="$(node -e 'console.log(require("crypto").randomBytes(32).toString("hex"))')"
export SFEBOOT_ALLOWED_ORIGIN=https://starkfiber.my
printf 'Your access token: %s\n' "$SFEBOOT_TOKEN"
sfeboot serve
Install & start on Windows

Download and unzip the source. Open PowerShell in the folder containing sfeboot, then run:

npm install -g ./sfeboot
$env:SFEBOOT_TOKEN = node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
$env:SFEBOOT_ALLOWED_ORIGIN = 'https://starkfiber.my'
Write-Host "Your access token: $env:SFEBOOT_TOKEN"
sfeboot serve

Run sfeboot serve with a token you generated. To connect from this site, explicitly set SFEBOOT_ALLOWED_ORIGIN=https://starkfiber.my. Browser local-network policies may require permission or block the connection; the CLI also serves this lab locally.

Your token stays in this page’s memory and is cleared on disconnect. It is never placed in a URL or saved to browser storage.

WINDOWS INSTALLER / REVIEWED LOCAL LAUNCH

Prepare the media.
See the installer.

Build media from your own Windows ISO and its trusted SHA-256. Then prepare a local QEMU launch plan. A plan is not a successful boot; Windows setup needs visible verification. No license terms are accepted automatically.

Verified case: Windows Server2025 Setup-only USB boot, mounted FAT32 volume and readable boot.wim. This reduced test media lacks installation payload; Setup reports missing media and cannot install Windows. The full-ISO builder remains experimental.
